**现代播放列表（Modern Playlist）** 是一款面向 foobar2000 的高性能原生 Windows 播放列表组件，具备流畅的 Direct2D/DirectWrite 渲染、面板内所有播放列表共用一套列布局、带可配置标题的专辑分组、异步封面、可交互的评分与喜爱标签、可自定义的封面背景、即时搜索、完整的拖放功能，以及集成的 Excel 风格播放列表管理器（支持播放列表锁定与状态栏）。

同一个 DLL 同时提供原生 **Default User Interface（DUI）** 元素和 **Columns UI（CUI）** 面板，无需 JavaScript 面板宿主。播放列表、元数据、播放、播放队列、锁定与撤销历史仍由 foobar2000 管理。

## 系统要求与安装

- **面向 Windows 的 foobar2000 2.0 或更高版本。** 本组件依赖播放列表 GUID，以便在重排、重命名和重启后仍能持久跟踪播放列表。
- **x64 或 Win32**，需与你的 foobar2000 安装架构一致。
- **Default UI 或 Columns UI。** Columns UI 为可选；Default UI 无需额外组件。

### 安装

1. 下载 `foo_modernplaylist.fb2k-component` 包。
2. 在 foobar2000 中依次打开 **文件 → 参数选项 → 组件**。
3. 点击 **安装…**，选择 `.fb2k-component` 文件，点击 **应用**，然后重启 foobar2000。
4. 确认 **现代播放列表** 已出现在已安装组件列表中。

本组件不会在 foobar2000 的参数选项中添加页面。每个面板的设置都位于其自身的 **[面板设置](#面板设置)** 对话框中。

## 添加面板

### Default UI

1. 选择 **视图 → 布局 → 启用布局编辑模式**。
2. 右键点击你想替换的元素（或添加一个新容器），选择 **播放列表渲染器 → 现代播放列表**。
3. 再次点击 **视图 → 布局 → 启用布局编辑模式** 退出编辑模式。

面板会继承 Default UI 的播放列表字体、标签字体和颜色，并即时跟随浅色与深色模式变化。

### Columns UI

1. 打开 **文件 → 参数选项 → 显示 → Columns UI → 布局**。
2. 将 **播放列表视图 → 现代播放列表** 插入你想要的拆分容器。
3. 点击 **应用**。

Columns UI 面板使用 Segoe UI 字体，并采用组件自有的浅色/深色配色与宿主强调色。两种宿主共用同一套实现；每个面板各自保存配置，包括 Columns UI 布局的导出/导入。

## 功能概览

- **Direct2D / DirectWrite 视口：** 平滑像素滚动、硬件加速渲染、局部重绘、触摸平移/惯性、MSAA 无障碍支持，以及带缓冲的 GDI 回退。
- **内置列：** 支持可配置的标题格式、附加行、排序表达式、DUI 风格相对颜色、`$rgb(r,g,b)` 颜色，以及电台流艺术家识别。
- **可交互评分与喜爱：** 点击 Material 星星通过播放统计或文件标签设置评分（1–5）；点击爱心切换喜爱曲目（`MOOD`）。
- **专辑分组：** 两行或三行标题，四条可配置文本行，曲目数与时长，标题封面，按播放列表指定模板，**不分组** 模板，以及自动折叠非播放分组。
- **自定义封面背景：** 音轨封面、音轨艺术家图片、带通配符的自定义图片或仿真透明，支持模糊、不透明度、变暗和裁剪模式。
- **搜索与快速定位：** 8 个搜索字段、播放列表过滤、媒体库搜索快照、按字段限定高亮，以及可配置的前缀键入搜索。
- **完整拖放：** 移动或按 Ctrl 复制曲目，拖到播放列表标签以追加副本，拖到 `+` 新建播放列表，并可直接从 Windows 文件资源管理器拖入文件。
- **主题化垂直滚动条：** 与当前主题匹配的自定义平滑滚动条，对称箭头、按比例调整的滑块，以及双击快捷操作。
- **Excel 风格播放列表管理器与状态栏：** 抗锯齿工作表标签、标签名中的彩色表情、就地重命名、定位正在播放按钮、用于保护播放列表的 **锁定**、总项数，以及一键 ↑ / ↓ 按名称排序播放列表。
- **面板设置对话框：** 六个标签页，支持 **应用**、**重置** 与 `.mpsettings` **导入…** / **导出…**，并跟随 foobar2000 的浅色/深色模式。

## 面板设置

- **最小行高：** 行通常使用宽松的现代高度（30 像素与字体高度加 10 中的较大者；带附加行时为 36 像素与 1.9 倍字体高度加 4 中的较大者）。启用该选项后，紧凑的经典行使用所输入的值（1 到 300 像素），但行绝不会小于字体高度加 2 像素。数值随 DPI 与面板缩放而缩放。

- **重置与导入** 与其他修改一样暂存，仅在点击 **应用** 或 **确定** 时生效。应用时，它们还会替换没有对应标签页的设置：搜索行可见性、字段、范围与高亮颜色；列标题可见性与对齐；播放列表标签可见性；滚动条与状态栏可见性；以及面板缩放。全局特殊播放列表选项与播放列表锁定不属于面板设置。

## 播放列表管理器与状态栏

- **定位正在播放的播放列表（◎）：** 激活正在播放的播放列表，并把它的标签滚动到可见位置（暂停时也可以）。如果该播放列表里没有搜索查询，还会定位到正在播放的曲目并展开它所在的分组。停止时，定位到选中的标签。

- **就地重命名：** 双击标签、按 `F2`，或在标签菜单里选 **重命名**，就能在标签上方的框里改名字，且名称默认全选。`Enter` 或 `Tab` 保存，`Escape` 取消，点别处也会保存。重命名期间所有按键都发给编辑框，所以 foobar2000 的快捷键不会作用到播放列表。管理器隐藏时，`F2` 改为打开重命名对话框。

- **键盘导航：** 管理器获得焦点后，用 `左`、`右`、`Home`、`End` 切换播放列表，按 `F2` 重命名当前播放列表。

- **锁定播放列表：** 会阻止添加、移除、重排、替换项目，以及重命名和移除播放列表；但双击播放、编辑标签、把曲目复制出去、移动标签仍然可用。

- **双击状态栏** 可显示正在播放的曲目。

- **特殊播放列表**（媒体库 / 播放记录 / 播放队列）按 GUID 跟踪，因此同名的现有播放列表绝不会被占用。

## 列与外观

### 着色与显示变量

- **DUI 风格相对颜色：** `<text>`、`<<text>>` 和 `<<<text>>>` 将文本颜色向行背景色变暗 25%、50% 或 75%；`>text<`、`>>text<<` 和 `>>>text<<<` 向高亮颜色混合。颜色在两种宿主中都会跟随主题、选中和正在播放行的变化而变化：
  ```text
  [%title% <<$ifequal(%itunesadvisory%,1,🅴,)>>]
  ```
- **内联颜色（`$rgb(r,g,b)`）：** 为后续文本着色，直到下一个颜色代码或行尾（值 0–255）。对于喜爱和评分列，第一个 `$rgb()` 会覆盖图标的强调色：
  ```text
  $if(%title%,$rgb(80,170,240)%title%,)
  $rgb(255,120,170)$if(%mood%,1,0)
  $rgb(255,255,50)$if2(%rating%,0)
  ```
  将颜色标记放在结果分支中，绝不要放在条件或比较中，并为彩色列使用单独的排序格式。
- **上下文变量：**
  - `%isplaying%`：仅对正在播放的曲目出现位置为 `1`（包括暂停时）；否则为空。
  - `%list_index%`：搜索过滤前曲目在播放列表中的基于 1 的索引。
  - `%list_total%`：搜索过滤前播放列表中的曲目总数。

## 可交互的特殊列

### 播放与队列状态

**状态** 列（`ref="State"`）提供紧凑的指示符：
- **空闲行：** 一个小而淡的方形框，随列变窄仍保持方形。已排队曲目以相同高度的淡色徽章显示紧凑、加粗的队列编号（`01`、`02`……）；重复的队列条目会列出所有位置（`01, 03`）。
- **选中：** 已选中、未加入队列、未播放的曲目显示一个细的、抗锯齿的矢量对勾（标称 18px），随 DPI 和缩放而缩放。
- **播放动画：** 播放时，每秒一次在实心三角形（Wingdings 3 `U+0075`）和空心三角形（`U+0077`）之间交替，位置固定。暂停时保持空心三角形。若 Wingdings 3 不可用，则使用 Segoe UI Symbol。
- **播放队列：** 显示每行自身的队列位置。

### 喜爱标签

**喜爱** 列（`ref="Mood"`）显示一个实心 Material 爱心（标称 15px）：
- 已喜爱的爱心为粉色（`RGB(255,120,170)`）；未激活的爱心为行文本颜色的淡色版本。默认格式：`$if(%mood%,1,0)`。
- **切换：** 点击爱心设置 `MOOD=1` 或移除 `MOOD` 标签。空输出、`0` 和 `?` 均视为未激活。

### 星级评分

**评分** 列（`ref="Rating"`）显示五个实心 Material 星星（标称 16px）：
- 实心星星为黄色（`RGB(255,255,50)`），带轻微阴影；空位显示淡色星星（**样式 1 - 星星**，默认）或小圆点（**样式 2 - 圆点**）。**间距** 提供 **默认** 或 **紧凑**。默认格式：`$if2(%rating%,0)`。
- **点击评分：** 点击任意星星（1–5）设置该评分。点击当前评分则清除。
- **拖动预览：** 在星星上拖动以预览；评分在松开时一次性提交。`Escape` 或离开该行会取消。
- **存储后端：** 安装了 `foo_playcount` 时使用 foobar2000 的 **播放统计** 评分命令，即使其菜单项被隐藏或翻译也能找到；否则写入或清除文件的 `RATING` 标签。

## 专辑分组

### 自动折叠与播放列表过滤

- **选择 / 折叠 / 展开：** 点击分组标题选择其曲目（包括折叠分组中隐藏的曲目）；双击折叠或展开该分组。**分组** 菜单还提供 **全部折叠**、**全部展开** 和 **默认折叠分组**。
- **自动折叠非播放分组：** 折叠除当前正在播放分组外的所有分组。手动展开或折叠会保持，直到正在播放的曲目改变。
- **播放列表过滤：** 启用 **分组 → 启用播放列表过滤** 后，每个模板以分号分隔的 **播放列表过滤** 按名称将其分配给播放列表；`*` 标记默认模板。显式名称优先于默认。分配生效期间，**更改分组模板** 灰显。过滤器只影响分组；所有播放列表仍共用面板的共享列。

例如，将 **不分组** 分配给 `电台;播放队列;播放记录`，并给 **专辑** 设置 `*` 过滤器，即可对音乐分组，同时让电台、播放队列和播放记录列表保持平铺。

## 搜索与快速定位

### 搜索栏与范围

面板获得焦点时按 `Ctrl+F`，中键单击播放列表或搜索框，或使用 **搜索 → 显示搜索栏** 切换搜索栏：

- **字段选择器：**
  - `所有字段`：完整 foobar2000 查询语法（`artist HAS radiohead`、`%rating% GREATER 3`、布尔 `AND`/`OR`/`NOT`）。
  - `艺术家`、`标题`、`专辑`、`流派`、`专辑艺术家`、`注释`、`路径`：在该字段中进行快速、不区分大小写的字面子串匹配。`路径` 搜索完整位置，包括目录、文件名和扩展名（或流 URL）。
- **范围选择器：**
  - `当前播放列表`：在停止输入 500 ms 后过滤可见曲目。
  - `媒体库`：搜索整个媒体库，并将结果写入名为 `媒体库搜索` 的可复用快照播放列表。
- **Escape** 清除框内容；隐藏该行会保留查询和过滤。无效查询会显示内联提示。

### 视图按钮

搜索行末端的两个图标按钮可切换视图，而不会排序曲目或清除搜索：
- **不分组视图** 关闭分组，同时保留当前模板和折叠偏好。
- **分组视图** 若当前模板有标题则启用它，否则启用第一个带标题的模板。

### 文本高亮

匹配的字面文本会在曲目单元格、附加行和分组标题中高亮：
- 按字段搜索只高亮从该字段绘制的格式（专辑搜索不会高亮匹配的艺术家）。
- 通过 **搜索 → 高亮颜色…** 更改高亮颜色；对比文本会自动选择。

### 前缀键入搜索（键入定位）

在曲目列表获得焦点时通过键入跳转曲目：
- **前缀匹配：** 匹配所配置字段的开头（例如键入 `AB` 会跳到 **ABBA**，而不是 Black Sabbath）。
- **键入搜索字段：** **面板设置 → 搜索** 选择 **艺术家**（默认）、**标题**、**专辑**、**流派**、**专辑艺术家**、**注释**、**路径** 或当前 **分组依据**。
- **浮层：** 一个大的居中浮层显示你键入的字符串和匹配状态。
- **超时：** 停止输入 **1 秒** 后或焦点离开列表时，已键入的前缀清除。按 `Backspace` 删除最后一个字符，或按 `Escape` 关闭。键入搜索绝不改变搜索框的查询或过滤。

## 拖放

现代播放列表提供完整的 OLE 拖放集成：

- **重排曲目：** 超过 Windows 拖动阈值并保持 150 ms 后，拖动选中的曲目重新定位。插入线标记目标位置，包括分组之前或之后。
- **复制曲目（按 Ctrl 拖动）：** 在播放列表内放下时按住 `Ctrl` 以插入副本。
- **放到播放列表标签上：** 将曲目放到任意标签上，将副本追加到该播放列表。
- **放到 `+` 按钮上：** 将曲目放到 **+** 上以创建、填充并激活一个新播放列表。
- **文件资源管理器拖入：** 从 Windows 资源管理器将音频文件、文件夹或受支持的播放列表文件拖入曲目列表、标签或 **+**。
- **外部拖动：** 将曲目拖动到其他 foobar2000 组件或外部应用程序。
- **锁定保护：** 智能列表和锁定的播放列表（包括用 **锁定** 锁定的播放列表）以标准的禁止光标拒绝被禁止的操作。

## 垂直滚动条

- **Shift+点击跳转：** 按住 `Shift` 点击轨道或滑块任意位置，可将滑块直接移到指针处；继续按住则作为普通滑块拖动继续。
- **双击快捷操作：** 双击滑块显示正在播放的曲目；双击箭头跳到顶部或底部。

## 悬停提示

- **定位模式：**
  - *显示选中曲目的悬停提示（默认）：* 悬停任意曲目都会显示播放列表顺序中的第一个选中曲目，包括屏幕外的曲目。
  - *悬停曲目：* 取消勾选该设置则显示鼠标光标下的曲目。
- **多行格式：** 在设置编辑器中按 `Enter`（或使用 `$char(10)`）可实现多行提示。悬停延迟可在 100 到 5,000 ms 之间配置。

### Windows：MSBuild（推荐）

需要带有 **MSVC v145** 工具集的 Microsoft C++ 生成工具、MSBuild 和 Windows SDK。在 Visual Studio 开发人员命令提示符或 PowerShell 中：

```powershell
msbuild foo_modernplaylist.sln /p:Configuration=Release /p:Platform=x64 /p:PlatformToolset=v145 /v:minimal
```

输出：`build/x64/Release/foo_modernplaylist.dll`。也提供 Win32 和 Debug 配置；请与 foobar2000 的架构匹配。
